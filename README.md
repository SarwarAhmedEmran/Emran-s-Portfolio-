🌐 Sarwar Ahmed Emran — Portfolio

A modern, responsive, and interactive personal portfolio website built using HTML, CSS, and JavaScript.
This site highlights my skills, projects, achievements, leadership, photography, and volunteering experiences, providing a dynamic way to connect with me.


🚀 Features
🖥️ General

Responsive design — Works seamlessly on desktops, tablets, and mobile devices.

Dark/Light mode toggle with persistent theme (saved via localStorage).

Loading screen with animated spinner for smooth entry.

Scroll progress bar showing page reading progress.

Smooth section animations (fade, staggered reveals, bounce effects).

Floating action buttons (FABs) for quick contact and CV download.

🎨 Visuals & Effects

Particle background animation using <canvas>.

Typing text effect showcasing multiple roles dynamically.

Staggered section reveals for skills, projects, experience, etc.

Skill bars & animated counters triggered on scroll.

3D hover skill cards with logos (C, C++, Python, HTML, CSS, JS, Photography).

📸 Gallery

Organized into categories: Volunteering, Photography, Leadership.

Clickable lightbox preview for high-resolution images.
